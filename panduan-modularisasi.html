01
Analisis Struktur File Asli
Apa yang ada di dalam index_html_final_bak.html

File saat ini mencampur tiga jenis konten dalam satu file. Ini membuatnya sulit di-maintain, di-debug, dan di-kolaborasikan.

🎨
CSS — Baris 27–843 ~850 baris styling: variabel tema, komponen, dark mode, animasi splash, layout semua halaman.
🏗️
HTML — Baris 845–1441 ~350 baris markup: splash screen, header, 4 halaman (Rekap, Absensi, Milestone, Settings), 8+ modal, bottom nav.
⚙️
JavaScript — Baris 1442–5196 ~3.700 baris logika: state, storage, helpers, 9 fitur utama, render functions, event handlers.
⚠️
Masalah utama single-file ini: Sulit scroll untuk menemukan bug · Tidak bisa parallel edit · Git diff berantakan · CSS global bisa konflik · Semua fungsi di scope global (polusi namespace) · Tidak ada pemisahan concern yang jelas.

Tahapan Migrasi Step-by-Step
Cara aman memecah file tanpa merusak fungsionalitas
1
Buat Struktur Folder
Buat folder css/ dan js/ di samping index.html. Buat semua file kosong terlebih dulu.
mkdir css js touch css/variables.css css/base.css css/components.css css/layout.css css/pages.css touch js/config.js js/helpers.js js/state.js js/tabs.js touch js/rekap.js js/absensi.js js/milestone.js js/settings.js touch js/export-import.js js/app.js
2
Pisahkan CSS ke 5 File
Buka index_html_final_bak.html, ambil semua isi di dalam tag <style> (baris 27–843), lalu distribusikan ke file CSS.

Perbarui <head> index.html

Pisahkan JavaScript — Mulai dari Fondasi
Ambil isi dari dalam <script> (baris 1442–5196). Pisahkan dimulai dari modul yang paling tidak bergantung ke modul lain.

Pisahkan Modul Fitur (satu per satu)
Pindahkan setiap kelompok fungsi ke file-nya. Lakukan satu modul sekaligus, lalu test di browser sebelum lanjut ke modul berikutnya.
🎯
Tips penting: Jangan pindahkan semua sekaligus. Pindah satu modul → buka browser → cek konsol error → baru lanjut ke modul berikutnya. Ini mempermudah debugging jika ada fungsi yang terlewat.

7
(Opsional) Catatan Penting untuk Buka di Browser Lokal
Browser tidak bisa load file JS lokal dengan file:// karena CORS policy. Ada dua cara mudah:
# Cara 1: Python (paling mudah, sudah ada di semua OS) python -m http.server 8080 # Buka: http://localhost:8080 # Cara 2: VS Code Extension "Live Server" # Install extension → klik kanan index.html → "Open with Live Server" # Cara 3: Node.js (jika sudah install) npx serve .
